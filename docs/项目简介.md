# 小乐AI · 高考志愿填报助手 — 项目简介

> 版本：v0.4.1（2026-08）｜定位：作品集 / 面试展示项目

---

## 一句话介绍

**小乐AI 是一个"多 Agent 协同 + RAG 知识库"驱动的高考志愿填报决策系统：Supervisor 中枢像指挥员一样调度 8+ 个专业员工 Agent（画像/匹配/就业/联网/写库），用十万级录取数据、张雪峰咨询风格和确定性风控引擎，帮"一家人"吵出共识、做出不后悔的志愿选择。**

---

## 项目背景

高考志愿填报是**高信息差 + 高决策风险 + 全家参与**的典型场景：

- **信息差**：全国 283,653 条录取数据、883 个专业、2817 所院校，普通家庭根本无法消化；
- **决策冲突**：家长看稳定、学生看兴趣、分数看位次、就业看趋势——"一家人吵架"是常态；
- **工具缺口**：传统填报工具只给分数线查询，无法完成"从数据到决策"的完整链路；通用大模型又爱"端水"，给不出明确建议。

小乐AI 针对这一场景，用**多 Agent 系统还原"专业顾问团队"的工作方式**：先收集画像，再分路查证数据，最后给出有立场、有依据、敢劝退的建议。

## 项目实现功能

### 1. 多 Agent 协同决策（核心）
- **Supervisor 路由中枢**：场景/路径/决心度三层意图识别 + 确定性关键词兜底
- **8+ 专业 Worker 员工**：profile（画像）/ parent（家长）/ family（家庭融合）/ match（分数位次）/ career（就业前景）/ web_search（联网）/ sql（结构化查询）/ write（写库）
- **Agent 间协作**：AgentCommunicationBus 通信总线（订阅/发布/请求响应/广播）+ ReflexionAgent 反思循环（评估→建议→重试→记忆）+ ResultFusion 结果融合（合并/投票/加权/专家）

### 2. RAG / 图谱 / 语料知识库
- **ChromaDB 向量检索 + FTS5 全文检索 + 关键词混合召回 + RRF 融合**（Recall@3=0.567）
- **知识域分权**（kb_scope）：不同 Agent 只能检索自己的知识域，跨库兜底打标
- **Neo4j 知识图谱**：院校-专业-职业-城市-政策 4242 节点，13 种查询类型
- **张雪峰对话语料库**（XuefengStore）：Milvus + 硅基流动 BGE-M3 embedding（1024 维），专业关键字窗口词检索，风格锚点注入合成回答；Milvus 不可达自动降级 Chroma

### 3. 确定性风控（防端水）
- SynthesisGuard 防端水引擎 + 红线审计 + 反方审计（5 视角 7 维度）+ 硬编码过滤（体检/预算/地域）——**回复不越界、不编数据**

### 4. 学习闭环（write_Agent + Harness）
- **write_Agent**：联网搜到但知识库没有的内容，唯一写权限 worker 校验/去重后自动入库——越用越懂
- **Harness 数据引导**：数据缺失时引导用户上传 CSV/Excel/PDF/图片，自动解析入库

### 5. 全模态交互
- 文字（SSE 真流式 token 级推送）/ 语音（VAD→ASR→TTS 情绪合成）/ 图片理解（VLLM）/ WebSocket 全双工

### 6. 工程化能力
- RAG 评估体系（30 条标注集 + Recall@k/MRR/NDCG@k）、用户画像 CRM 断点续传、意图追踪、成本控制、重试熔断、CI 测试

## 项目思路

1. **中枢-员工（Sisyphus）模式**：不做"对话式多 Agent 互相聊天"，而是 Supervisor 作为指挥中枢，把任务拆解下发给专业 Worker 员工，员工采集信息后交回中枢汇总——**架构清晰、职责单一、可 review**
2. **数据分层治理**：确定性数据（分数线/风控规则）走 SQL/硬编码，经验知识走 RAG，关系知识走图谱，对话风格走雪峰语料库——**各层各司其职，互相降级兜底**
3. **可解释可问责**：每个推荐都带数据理由 + 风险提示 + 审计报告，风控信号不被 LLM 篡改——**拒绝黑箱**
4. **学习协作机制**：write_Agent 写库 + Harness 引导补数据 + 反馈闭环优化，让系统在真实使用中持续进化——**越用越懂**
5. **技术选型**：LangGraph（状态机编排，天然支持 Checkpoint 持久化多轮状态）+ FastAPI（异步流式）+ Vue 3（前端 SPA）+ SQLite/Neo4j/ChromaDB/Redis（分层数据）

## 技术栈速览

| 层 | 技术 |
|---|---|
| 编排 | LangGraph 1.x（多智能体图 + Checkpoint） |
| 后端 | FastAPI + Uvicorn（SSE/WebSocket 流式） |
| 前端 | Vue 3 + Vite SPA（Vue Router 7 路由） |
| 数据 | SQLite（283,653 条录取数据）+ Neo4j（知识图谱）+ ChromaDB/Milvus（向量）+ Redis（会话） |
| Embedding | 硅基流动 BGE-M3 API（1024 维，`embedding_provider: siliconflow` 单一真源可切本地） |
| LLM | DeepSeek V4 / Qwen / GLM / Kimi / Ollama 多供应商 + 自动回退熔断 |
| 语音视觉 | FunASR / EdgeTTS / Silero VAD / GLM-4V 多模态 |
| 测试 | pytest 200+ 用例 + CI（GitHub Actions） |
