# 常见问题 ❓

## 一、环境与启动

### 1. 首次启动时长时间卡住不动？

首次启动需要下载 `paraphrase-multilingual-MiniLM-L12-v2` 嵌入模型（约 420MB）。

**解决方案**：
- **国内用户**：设置 `HF_ENDPOINT=https://hf-mirror.com`（在 `.env` 中）
- **已下载过**：模型会缓存在 HuggingFace 本地目录，后续启动秒开

```bash
# .env 中添加
HF_ENDPOINT=https://hf-mirror.com
```

### 2. 报错 "DeepSeek API Key 未配置"？

在 `.env` 文件中设置：

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

或在 `configs/.config.yaml` 的 `api_keys` 段直接填写：

```yaml
api_keys:
  DEEPSEEK_API_KEY: "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

### 3. 报错 `401 Invalid API Key` / `openai.AuthenticationError`

**原因**：API Key 未配置、格式不对、已过期或余额不足。

**排查步骤**：
1. 检查 `.env` 确认 `DEEPSEEK_API_KEY` 已填写
2. 确认 Key 格式正确（DeepSeek 以 `sk-` 开头）
3. 确认 Key 未过期且有余额（登录平台控制台查看）
4. 如果使用代理或自定义 API 地址，检查 `OPENAI_BASE_URL` 配置

**临时测试**：可以直接使用 DEEPSEEK 官方 API 验证：

```powershell
curl -X POST https://api.deepseek.com/chat/completions ^
  -H "Content-Type: application/json" ^
  -H "Authorization: Bearer sk-xxxxxxxxxxxxxxxx" ^
  -d "{\"model\":\"deepseek-chat\",\"messages\":[{\"role\":\"user\",\"content\":\"hi\"}]}"
```

### 4. PostgreSQL 连接不上怎么办？

系统会自动降级到 SQLite 本地数据库。不配置 PostgreSQL 不影响核心功能。

如果需要使用 PostgreSQL：

```bash
# 确认 PostgreSQL 已启动
sudo systemctl status postgresql

# 检查 .env 中的密码配置
POSTGRES_PASSWORD=your_password
```

### 5. Redis 连接失败怎么办？

Redis 用于会话历史存储，连接失败不影响核心对话功能。系统会自动降级。

```bash
# 确认 Redis 已启动
redis-cli ping
# 应返回 PONG

# .env 中配置
REDIS_HOST=localhost
REDIS_PORT=6379
```

### 6. 端口 8000 被占用？

```powershell
# Windows
netstat -ano | findstr :8000
taskkill /PID <pid> /F

# Linux/macOS
lsof -i :8000
kill -9 <pid>
```

如果端口被系统保留无法释放，可修改端口：

1. 编辑 `api/main.py` 中 `uvicorn.run("api.main:app", host="0.0.0.0", port=8001, ...)`
2. 同步修改 `frontend/vite.config.js` 中的 proxy target 端口
3. 重新构建前端

### 7. 前端页面空白 / 看不到导航按钮和设置按钮？

**原因**：Vite 构建产物缺失或过期。

```powershell
cd frontend
npm install
npm run build
cd ..
```

重新启动后端后刷新浏览器。

### 8. 管理员端显示"管理后台功能正在迁移中"？

这是旧版占位文本，V7.0 后已替换为功能面板。如果仍然显示，请：

1. 确认已执行 `npm run build`（前端构建）
2. 清空浏览器缓存
3. 重新登录

### 9. 前端构建报错

```powershell
cd frontend
npm install
# 如果 npm install 失败，尝试：
npm install --legacy-peer-deps

# 构建
npm run build
```

## 二、数据库与 RAG

### 10. 向量数据库（ChromaDB）不工作

页面服务状态显示向量库异常（❌）。

**原因**：RAG 索引未构建或 ChromaDB 数据目录缺失。

**解决**：

```powershell
# 构建 RAG 索引
python scripts/build_rag_index.py

# 验证
python -c "import json; d = json.load(open('data/vector_store/zx_experience.json')); print(f'{len(d)} 条文档')"
```

### 11. 知识图谱（Neo4j）不工作

页面服务状态显示知识图谱异常（❌）。

**原因**：Neo4j 服务未运行或未导入图谱数据。

**解决**：

```powershell
# 启动 Neo4j（Docker）
docker run -d --name neo4j -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/password neo4j:5.15-community

# 导入数据
python scripts/import_neo4j.py

# 测试连接
python -c "from neo4j import GraphDatabase; d = GraphDatabase.driver('bolt://localhost:7687', auth=('neo4j','password')); d.verify_connectivity(); print('OK'); d.close()"
```

### 12. 院校排名 API 返回空数据

**原因**：排名数据文件缺失或 API 路由返回空。

**排查**：

1. 检查后端日志是否有排名相关报错
2. 检查 `frontend/public/assets/ranking_data.json` 是否存在
3. 如果使用本地数据回退，需将该文件放在 `frontend/public/assets/` 下并重新构建

```powershell
# 构建后，文件位于 frontend/dist/assets/ranking_data.json
# 可直接通过 http://127.0.0.1:8000/assets/ranking_data.json 访问验证
```

### 13. 用户画像数据跨会话丢失？

系统依赖手机号（CRM）持久化保存用户画像。如果未配置手机号，画像仅在当前会话有效。

## 三、语音交互

### 14. 语音按钮不可见或禁用（带麦克风斜杠图标）

**原因**：浏览器不支持或麦克风权限被拒绝。

**解决**：
- 使用 Chrome / Edge 最新版本
- 确保通过 HTTPS 或 localhost 访问
- 浏览器地址栏左侧 🔒 → 网站设置 → 麦克风 → 允许
- 检查是否有其他应用占用了麦克风

### 15. 语音识别不准确？

- 确保麦克风权限已授予浏览器
- 在安静环境下录音
- 说话清晰，语速适中
- 检查 `configs/.config.yaml` 中 ASR 引擎是否正确配置

### 16. TTS 语音合成失败？

**Edge TTS（默认，免费）**：
- 需要网络连接（访问微软 Edge TTS 服务）
- 如果使用代理，可能需要关闭代理

**CosyVoice**：
- 需要配置 `SILICONFLOW_API_KEY`
- 在 `configs/.config.yaml` 中切换 TTS 引擎

## 四、模型与配置

### 17. 如何切换 LLM 模型？

编辑 `configs/.config.yaml`：

```yaml
selected_module:
  LLM: qwen3.7-flash  # 改成你要用的模型
```

可选模型：`deepseek-v4-flash`、`qwen3.7-plus`、`qwen3.7-max`、`glm-5.1-flash`、`glm-5.1-pro` 等。

### 18. 如何使用本地 Ollama 模型？

1. 安装 Ollama：https://ollama.ai
2. 拉取模型：`ollama pull qwen2.5:14b`
3. 配置 `.config.yaml`：

```yaml
selected_module:
  LLM: LocalQwen
```

### 19. API Key 支持哪些配置方式？

三种方式（优先级从高到低）：

1. `.config.yaml` 的 `api_keys` 段直接填写
2. `.config.yaml` 的 `api_keys` 段用 `${ENV_VAR}` 引用环境变量
3. `.env` 文件中的环境变量

## 五、界面与交互

### 20. 太阳/月亮暗色模式切换按钮点击无反应？

**原因**：Vite 构建后 CSS 选择器冲突或 Vue 响应式绑定问题。

**解决**：
1. 确认已执行 `npm run build`（最新构建包含修复）
2. 清空浏览器缓存硬刷新（Ctrl+F5）
3. 也可通过 **设置面板**（header 右上角 ⚙ 按钮）切换深色模式

### 21. 找不到设置按钮？

设置按钮在登录后 header 右上角，用户信息旁 ⚙ 图标。点击打开设置面板，可调整：
- 深色模式切换
- 主题颜色（蓝/橙/绿/紫/红/青）
- 语音合成设置

### 22. 管理员端多了用户端导航按钮（对话/排名/图谱）

**原因**：localStorage 中缓存的用户角色信息异常。

**解决**：清空缓存后重新登录

```js
// 浏览器控制台执行
localStorage.removeItem('auth_token')
localStorage.removeItem('user_info')
// 然后刷新页面重新登录
```

### 23. 院校排名没有排名字段/滑动器？

V7.0 前端已添加排名数量滑动器（5/10/20/50/100）和分页控件。如果仍然看不到：

1. 确认已执行 `npm run build`
2. 清空浏览器缓存硬刷新
3. 检查 API 是否返回数据（F12 → 网络 → `api/ranking` 请求）

### 24. 语音对话按钮在哪里？

语音输入按钮位于聊天框输入区域的左侧，是一个麦克风 🎤 图标按钮。支持浏览器麦克风的设备：
- 点击开始录音
- 再次点击停止
- 自动将语音转为文字发送

## 六、知识库与 RAG

### 25. 如何更新知识库？

```bash
# 方式一：上传文件自动解析
curl -X POST http://127.0.0.1:8000/rag/upload -F "file=@document.pdf"

# 方式二：扫描目录重建索引
curl -X POST http://127.0.0.1:8000/rag/scan-documents

# 方式三：通过设置界面
# 设置 → 高级 → 知识库管理
```

### 26. 支持哪些文件格式？

| 格式 | 扩展名 | 说明 |
|------|--------|------|
| Markdown | `.md` | 按段落分块 |
| CSV | `.csv` | 按行列拼接 |
| PDF | `.pdf` | pdfplumber 提取 |
| 纯文本 | `.txt` | 原样提取 |

### 27. 向量检索和全文检索有什么区别？

- **向量检索（ChromaDB）**：语义相似度匹配，"计算机就业前景" 能匹配到 "IT 行业发展"
- **全文检索（SQLite FTS5）**：关键词精确匹配，"计算机" 只匹配包含 "计算机" 的文档
- **关键词混合召回**：本地 JSON 文件的词频+语义混合匹配

系统自动按优先级使用：向量 → 全文 → 关键词

## 七、部署与运维

### 28. Docker 部署失败？

```bash
# 检查 Docker 是否运行
docker info

# 重建容器
docker-compose down
docker-compose up -d --build

# 查看日志
docker-compose logs -f api
```

### 29. 如何备份数据？

```bash
# SQLite
cp data/zx_advisor.db backup/zx_advisor_$(date +%Y%m%d).db

# ChromaDB
cp -r data/chroma_db backup/chroma_db_$(date +%Y%m%d)

# 配置
cp configs/.config.yaml backup/config_$(date +%Y%m%d).yaml
```

### 30. 如何查看服务状态？

```bash
# API 健康检查
curl http://127.0.0.1:8000/healthz

# 详细状态
curl http://127.0.0.1:8000/status

# 管理员面板
# 浏览器打开 http://127.0.0.1:8000 → 管理员登录 → 系统监控
```

### 31. 日志在哪里？

- 控制台输出：启动时直接可见
- 日志文件：`logs/` 目录（如果配置了文件日志）
