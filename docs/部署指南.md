# 部署指南

## 方式一：本地开发部署

适用场景：个人使用、开发调试。

### 环境要求

- Python 3.10+
- Conda（推荐）或 venv
- Node.js 18+（构建前端时需要）
- Redis（可选，用于会话缓存）
- Neo4j（可选，用于知识图谱）

### 快速启动

```bash
# 1. 克隆项目
git clone <repo-url> && cd 小乐高考志愿填报助手

# 2. 创建虚拟环境
conda create -n zxf python=3.10 -y && conda activate zxf

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置
copy .env.example .env
# 编辑 .env 填写 API Key（见下方"API Key 配置"章节）
# 编辑 configs/.config.yaml 选择模型

# 5. 构建前端（Vite 打包）
cd frontend
npm install
npm run build
cd ..

# 6. 初始化数据（首次部署必需）
python scripts/init_sqlite.py
python scripts/build_rag_index.py

# 7. 启动服务
python -m api.main
```

### 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端 UI | http://127.0.0.1:8000 | Vite 构建的 SPA（由 FastAPI 直接 serve） |
| API 文档 | http://127.0.0.1:8000/docs | Swagger UI |
| 健康检查 | http://127.0.0.1:8000/healthz | 服务状态 |

> **注意**：V7.0 已弃用 Flask UI（旧端口 5000），前端改为 Vite 构建后由 FastAPI 在 `8000` 端口统一 serve。

### 初始化数据脚本

```powershell
# 一键导入（推荐）
python scripts/import_all.py

# 分步执行
python -m scripts.init_sqlite                          # 建表
python -m scripts.import_gaokao_from_xlsx               # 导入高考录取数据
python -m scripts.build_rag_index                       # 构建 RAG 索引
python -m scripts.import_neo4j                          # 导入知识图谱（需 Neo4j 运行中）
```

**一键导入脚本参数:**

| 参数 | 说明 |
|------|------|
| `--skip-gaokao` | 跳过高考数据导入 |
| `--skip-rag` | 跳过 RAG 索引构建 |
| `--stats` | 仅显示统计信息 |

```powershell
# 示例：跳过高考数据导入
python scripts/import_all.py --skip-gaokao

# 示例：仅查看统计
python scripts/import_all.py --stats
```

## 模型配置

### 默认模型

项目默认使用 DeepSeek V4 Flash：

```yaml
# configs/.config.yaml
selected_module:
  LLM: deepseek-v4-flash   # 大模型
  ASR: FunASR              # 语音识别
  TTS: EdgeTTS             # 语音合成
  VLLM: glm-4v-flash       # 视觉模型
```

### 切换模型

编辑 `configs/.config.yaml` 的 `selected_module`：

```yaml
selected_module:
  LLM: qwen3.7-plus      # 改为通义千问
  ASR: FunASR
  TTS: CosyVoice
```

可用模型列表见 `configs/.config.yaml` 中的注释。

## API Key 配置

### 必需配置

至少提供一个 LLM 的 API Key，编辑 `.env` 文件：

```ini
# DeepSeek（默认模型）
DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 或通义千问
DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 或智谱 GLM
ZHIPU_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 常见错误

**错误：`401 Invalid API Key` / `AuthenticationError`**

原因：API Key 未配置、格式不对或已过期。

排查：
1. 检查 `.env` 中 `DEEPSEEK_API_KEY` 是否已填写
2. 确认 Key 格式正确（DeepSeek Key 以 `sk-` 开头）
3. 确认 Key 未过期且有余额
4. 如果使用自定义 API 地址，检查 `OPENAI_BASE_URL` 配置

## 常见部署问题

### 1. 端口 8000 被占用

```powershell
# 查找占用进程
netstat -ano | findstr :8000

# 终止进程（PID 替换为实际值）
taskkill /PID 12345 /F

# 或直接换端口
# 修改 api/main.py 中 uvicorn.run 的 port=8001
# 同时修改 frontend/vite.config.js 的 proxy target
```

### 2. 前端空白 / 按钮不显示

**原因**：前端未构建或构建产物缺失。

**解决**：

```powershell
cd frontend
npm install
npm run build    # 确保 dist/ 目录生成且包含 index.html + assets/
cd ..
```

构建成功后重新启动后端。

### 3. 向量数据库（ChromaDB）不工作

页面显示向量库异常，通常是因为 RAG 索引未构建。

```powershell
python scripts/build_rag_index.py
```

### 4. 知识图谱（Neo4j）不工作

页面显示知识图谱异常，通常因为 Neo4j 服务未启动。

```powershell
# 启动 Neo4j（Docker 方式）
docker run -d --name neo4j -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/password neo4j:5.15-community

# 导入图谱数据
python scripts/import_neo4j.py
```

### 5. 语音按钮不可用

浏览器需要授予麦克风权限。如果按钮显示为禁用状态（麦克风带斜杠图标），说明浏览器不支持或权限被拒绝。

- 使用 Chrome / Edge 最新版本
- 检查页面是否通过 HTTPS 或 localhost 访问
- 在浏览器地址栏左侧点击🔒图标 → 网站设置 → 麦克风 → 允许

### 6. 管理员登录后导航按钮混乱

管理员账号登录后 header 默认只显示品牌和退出按钮（不显示 对话/排名/图谱 等用户端按钮）。
如仍然显示多余的导航按钮，清空浏览器 localStorage 后重新登录：

```js
// 浏览器控制台执行
localStorage.clear()
```
