# 专升本考试指南

## 什么是专升本

专升本考试是指大学专科（高职高专）学生进入本科层次阶段学习的选拔考试，是中国大陆教育体制中，专科层次学生升入本科院校的考试制度。

## 专升本主要类型

1. **普通专升本**：全日制在校专科生，大三下学期参加全省统考
2. **自考专升本**：自学考试，适合在职人员
3. **成考专升本**：成人高考，全国统一命题
4. **网络教育专升本**：网络教育，部分高校开设

## 各省政策差异

每个省份的专升本政策不同，主要包括：
- 考试时间：多数省份在3-4月
- 考试科目：通常为2-3门（公共课 + 专业课）
- 招生院校：省内本科院校为主
- 报考条件：专科期间无违纪、成绩合格

## 专升本院校推荐原则

1. 优先选择本省公办本科院校
2. 结合专业对口度选择
3. 考虑地理位置和就业机会
4. 关注历年录取分数线和报录比

## 专升本复习建议

1. 公共课（英语/高数）：大二开始准备
2. 专业课：大三上学期学完第一轮
3. 真题训练：考前3个月集中刷题
4. 关注省教育考试院官网公告
