# 专升本各省政策对比

## 全国概况

专升本考试由各省自行组织，政策各不相同。核心差异在于：
- 考试时间（集中在3-5月）
- 考试科目（2-4门不等）
- 报考条件（是否允许跨专业、跨校）
- 招生规模（省内公办/民办本科）

## 报考条件

1. **应届专科毕业生**（绝大多数省份）
2. **专业对口**（多数省份）vs **允许跨专业**（广东、上海等少数）
3. **英语等级要求**（上海需四级、北京推荐）
4. **在校期间无违纪记录**（所有省份）

## 选省决策树

```
你专科在哪里读的？
├─ 广东/上海 → 可以跨专业、跨校，选择空间大
├─ 江苏/浙江 → 仅限省内名校，竞争激烈
├─ 山东/河南 → 考生体量大，可以校荐+自荐
├─ 湖北/四川 → 可跨校但不可跨专业
└─ 其他省份 → 对口升本，需要提前查目标院校
```

## 时间规划建议

| 时间节点 | 行动 |
|---------|------|
| 大一暑假 | 了解本省专升本政策，确定目标方向 |
| 大二上学期 | 开始系统复习公共课（英语/高数） |
| 大二暑假 | 专业课第一轮复习 |
| 大三9月 | 确定目标院校，查往年分数线 |
| 大三10-12月 | 报名、第二轮复习 |
| 大三1-3月 | 考前冲刺，真题模拟 |
| 大三4-5月 | 参加考试 |
| 大三6月 | 出成绩、填报志愿 |
