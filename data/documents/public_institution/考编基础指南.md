# 事业单位考试指南

## 什么是事业单位

事业单位是指国家为了社会公益目的，由国家机关举办或者其他组织利用国有资产举办的，从事教育、科技、文化、卫生等活动的社会服务组织。

## 考试类型

1. **联考**：多省统一命题（每年5月、10月）
2. **统考**：省内地市级统一考试
3. **单位单独招聘**：医院、学校等自主招聘

## 考试科目

| 岗位类别 | 考试科目 |
|---------|---------|
| 综合管理类 (A类) | 职测 + 综应 |
| 社会科学专技类 (B类) | 职测 + 综应 |
| 自然科学专技类 (C类) | 职测 + 综应 |
| 中小学教师类 (D类) | 职测 + 综应 |
| 医疗卫生类 (E类) | 职测 + 综应 |

## 公共基础知识内容

- 政治（30%）：马哲、中特、时政
- 法律（25%）：宪法、行政法、民法、刑法
- 经济（15%）：微观、宏观经济学
- 管理（10%）：行政管理学基础
- 公文（10%）：公文写作格式
- 科技文史（10%）

## 考编 vs 考公的区别

1. 编制性质：公务员是行政编制，事业单位是事业编制
2. 考试难度：考公总体难度 > 考编
3. 待遇：同地区公务员略优于事业单位
4. 晋升：公务员晋升通道更明确
