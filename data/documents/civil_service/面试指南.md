# 公务员面试指南

## 面试形式

### 结构化面试
- 固定题目、固定评分标准
- 通常 3-4 题，15-20 分钟
- 7-9 名考官 + 2名监督员

### 无领导小组讨论
- 8-10 人一组，45-60 分钟
- 给定讨论话题，自由发言
- 考察团队协作、逻辑思维、表达沟通

### 结构化小组
- 3 人一组，互相点评
- 先各自答题，再互相点评和回应
- 考察批判性思维和合作精神

## 常见面试题类型

1. **综合分析类**：你怎么看待"躺平"现象？
2. **计划组织类**：单位要举办一场培训，你怎么安排？
3. **应急应变类**：群众来上访情绪激动，你怎么处理？
4. **人际沟通类**：和领导意见不一致，你怎么办？
5. **自我认知类**：为什么报考这个岗位？

## 答题技巧

1. **STAR 法则**：情境 → 任务 → 行动 → 结果
2. **总分结构**：先亮观点，再展开论述
3. **时间控制**：每道题 3-5 分钟，不要超时
4. **仪态管理**：眼神交流、坐姿端正、适度的肢体语言

## 面试着装建议

- 男士：深色西装 + 浅色衬衫 + 领带 + 皮鞋
- 女士：职业套装或连衣裙 + 淡妆
- 核心：干净、整洁、精神、得体
