# 行测备考攻略

## 行测考试特点

行测（行政职业能力测验）是公务员考试必考科目，满分100分，考试时间120分钟。

核心挑战：**时间压力极大**。平均每题只有50秒，必须掌握速解技巧。

## 各模块攻破策略

### 1. 资料分析（目标正确率 90%）

这是行测中最容易拿高分的模块。关键是：
- 不需要精算！用估算法、截位法
- 掌握常用公式：增长率、比重、倍数
- 先看题目再看材料，带着问题找数据

### 2. 言语理解（目标正确率 80%）

- 逻辑填空：先看语境，再看选项
- 阅读理解：首尾句法，主题词定位
- 不要脑补！所有答案都在原文中

### 3. 判断推理（目标正确率 75%）

- 图形推理：对称/旋转/数量/叠加
- 逻辑判断：充分必要条件、真假推理
- 定义判断：关键字提取法

### 4. 数量关系（目标正确率 60-70%）

- 优先做工程问题、行程问题、利润问题
- 排列组合和概率问题放在最后
- 没时间做的统一蒙，不要空题

### 5. 常识判断（目标正确率 50-60%）

- 不用专门复习，靠日常积累
- 重点看近半年时政热点
- 法律、党史、科技常识高频出现

## 时间分配建议

| 模块 | 建议用时 | 题量 |
|------|---------|------|
| 常识判断 | 10分钟 | 20题 |
| 言语理解 | 35分钟 | 40题 |
| 数量关系 | 15分钟 | 10-15题 |
| 判断推理 | 35分钟 | 40题 |
| 资料分析 | 25分钟 | 20题 |

## 推荐复习顺序

1. 先学资料分析（性价比最高）
2. 再学言语理解 + 判断推理
3. 最后学数量关系
4. 常识靠日常积累
