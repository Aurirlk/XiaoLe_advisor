# 考研复试攻略

## 复试形式

| 形式 | 说明 |
|------|------|
| 线下面试 | 到校参加面试，通常包含笔试+面试 |
| 线上面试 | 远程视频面试（疫情后常见） |
| 笔试+面试 | 传统复试模式，先笔试后面试 |

## 复试内容

### 1. 专业课笔试（30-50%）
- 内容：比初试更深，更贴近研究方向
- 准备：复习初试的教材 + 目标院校推荐的复试参考书

### 2. 综合面试（30-50%）
- 自我介绍（1-2分钟）— 突出学术能力和科研经历
- 专业问答 — 老师根据你的本科成绩单/简历提问
- 研究计划 — 说一下你研究生阶段想研究什么

### 3. 英语口试（10-20%）
- 英文自我介绍
- 英文问答（为什么选这个学校/专业）
- 英文文献翻译

## 复试高频问题

1. "为什么选择我们学校/专业？"
2. "你本科做过什么科研/项目？"
3. "你想研究什么方向？了解这个方向的导师吗？"
4. "如果你没被录取，你还会考研吗？"
5. "你对研究生生活有什么规划？"

## 复试准备清单

- [ ] 个人简历（突出学术/项目经历）
- [ ] 本科成绩单
- [ ] 四六级/雅思托福成绩
- [ ] 发表的论文/专利/竞赛获奖
- [ ] 推荐信（如果目标院校要求）
- [ ] 研究计划书（博士申请必须）
