小乐高考志愿填报助手 - 数据需求清单
========================================

生成时间: 2026-06-19
当前版本: v0.2.0

一、已有数据（可直接使用）
--------------------------

1. 录取分数线数据
   - 来源: SQLite admission_scores 表
   - 数量: 283,653 条
   - 覆盖: 2016-2020年，29个省份，2,702所院校
   - 字段: 院校ID、省份、科类、年份、专业名、最低分、最低位次

2. 院校基础信息
   - 来源: SQLite universities 表 + Neo4j University 节点
   - 数量: 2,817 所
   - 字段: 名称、层次、城市、标签、保研率

3. 专业信息
   - 来源: 爬取自阳光高考网
   - 数量: 883 个
   - 覆盖: 13个门类，所有本科专业
   - 字段: 名称、代码、门类、专业类

4. 城市基础数据
   - 来源: JSON + Neo4j
   - 数量: 306 个城市
   - 字段: 名称、省份、等级（一线~五线）

5. 行业数据
   - 来源: JSON + Neo4j
   - 数量: 50 个行业
   - 字段: 名称、部门、增长率、平均薪资

6. 技术趋势数据
   - 来源: JSON + Neo4j
   - 数量: 30 项技术
   - 字段: 名称、领域、成熟度、关联专业

7. 人才政策数据
   - 来源: JSON + Neo4j
   - 数量: 29 条政策
   - 字段: 名称、城市、类型、补贴金额

8. 薪资数据（部分城市）
   - 来源: JSON + Neo4j
   - 数量: 79 条
   - 覆盖: 北京、上海、深圳、广州、杭州、成都等主要城市
   - 字段: 城市、行业、平均薪资、中位数、P90


二、缺失数据（需要补充）
--------------------------

【优先级 P0 - 核心功能必需】

1. 一分一段表
   - 说明: 考生分数对应的省排名，是志愿填报的核心数据
   - 格式: 省份、年份、科类、分数、本段人数、累计人数
   - 来源: 各省教育考试院
   - 状态: 需要用户上传或API获取

2. 批次控制线
   - 说明: 本科一批/二批/专科的分数线
   - 格式: 省份、年份、科类、批次、分数线
   - 来源: 各省教育考试院
   - 状态: 需要用户上传或API获取

3. 招生计划
   - 说明: 各校各专业的招生人数
   - 格式: 省份、年份、院校、专业、科类、计划人数、批次
   - 来源: 阳光高考网、各校招生简章
   - 状态: 需要用户上传或API获取

4. 最新录取分数线（2024-2025）
   - 说明: 当前数据只有2016-2020年，需要最新数据
   - 格式: 同现有admission_scores表
   - 来源: 阳光高考网、各省考试院
   - 状态: 需要爬取或用户上传


【优先级 P1 - 就业分析必需】

5. 专业就业去向数据
   - 说明: 各专业的就业率、升学率、考公率、行业流向
   - 格式: 专业、年份、院校层次、就业率、升学率、考公率、前3行业、前3城市
   - 来源: 教育部就业质量报告、各校就业报告
   - 状态: 无数据，需要采集
   - 表结构: major_destination_stats（已建表，无数据）

6. 专业薪资统计数据
   - 说明: 各专业不同城市的薪资分布
   - 格式: 专业、城市、年份、入门薪资、3年薪资、5年薪资
   - 来源: 招聘平台报告（BOSS直聘、猎聘、智联）
   - 状态: 无数据，需要采集
   - 表结构: major_salary_stats（已建表，无数据）

7. 专业稳定性指标
   - 说明: 离职率、合同类型、行业周期性
   - 格式: 专业、年份、1年离职率、3年离职率、编制比例
   - 来源: 劳动统计局、招聘平台报告
   - 状态: 无数据，需要采集
   - 表结构: major_stability_stats（已建表，无数据）

8. 职业发展路径
   - 说明: 各专业的职业晋升路径和天花板
   - 格式: 专业、入门岗位、中期岗位、天花板岗位、AI替代风险
   - 来源: 行业报告、招聘平台数据
   - 状态: 无数据，需要采集
   - 表结构: major_career_path（已建表，无数据）


【优先级 P2 - 城市分析必需】

9. 城市详细数据
   - 说明: GDP、房价、生活成本、产业结构
   - 格式: 城市、省份、GDP、人均GDP、平均工资、房价指数
   - 来源: 国家统计局、各市统计公报
   - 状态: JSON中有基础数据，缺少经济指标
   - 表结构: city_data（已建表，无数据）

10. 城市高校资源
    - 说明: 各城市的高校数量、985/211分布
    - 格式: 城市、高校数量、是否有985、是否有211
    - 来源: 教育部数据
    - 状态: 可从现有universities表统计

11. 城市落户政策
    - 说明: 各城市的人才引进、落户政策
    - 格式: 城市、政策名称、类型、学历要求、补贴金额
    - 来源: 各市政府官网
    - 状态: JSON中有29条，需要扩充


【优先级 P3 - 院校分析必需】

12. 院校详细信息
    - 说明: 官网、学科数量、专业设置、师资力量
    - 格式: 院校名称、官网、博士点数、硕士点数、重点学科
    - 来源: 院校官网、教育部数据
    - 状态: 现有数据缺少这些字段

13. 院校排名数据
    - 说明: QS、US News、软科等排名
    - 格式: 院校、排名类型、年份、排名位次
    - 来源: ranking_data.json
    - 状态: JSON中有数据，需要导入SQLite

14. 院校满意度评分
    - 说明: 学生对院校的满意度评价
    - 格式: 院校、评分、评价人数
    - 来源: 阳光高考网
    - 状态: 爬取时已获取部分数据


【优先级 P4 - 增强功能】

15. 专业课程设置
    - 说明: 各专业的核心课程和选修课程
    - 格式: 专业、课程名称、学分、必修/选修
    - 来源: 各校培养方案
    - 状态: 无数据

16. 考研数据
    - 说明: 各专业的考研率、考研方向、难度
    - 格式: 专业、考研率、热门方向、报录比
    - 来源: 研招网、各校研究生院
    - 状态: 无数据

17. 出国留学数据
    - 说明: 各专业的留学率、热门国家、申请要求
    - 格式: 专业、留学率、热门国家、语言要求
    - 来源: 留学中介报告、各校国际处
    - 状态: 无数据

18. MBTI性格匹配
    - 说明: 不同性格适合的专业方向
    - 格式: MBTI类型、推荐专业、匹配理由
    - 来源: 心理学研究、职业规划报告
    - 状态: 无数据


三、数据采集建议
------------------

1. 优先采集P0数据（一分一段、批次线、招生计划）
   - 方案: 引导用户上传 + Harness机制自动解析
   - 预计: 用户上传为主，系统自动入库

2. P1就业数据可通过爬虫采集
   - 来源: 阳光高考网就业质量报告、BOSS直聘薪资报告
   - 方案: 定期爬取 + 人工审核

3. P2城市数据可从统计局获取
   - 来源: 国家统计局年鉴、各市统计公报
   - 方案: 批量下载 + 结构化处理

4. P3院校数据可从现有数据推导
   - 方案: 从universities表统计 + 网络补充

5. P4增强功能可在核心功能完善后再做


四、数据存储规划
-----------------

| 数据类型 | 存储位置 | 更新频率 |
|---------|---------|---------|
| 录取分数线 | SQLite admission_scores | 年度更新 |
| 一分一段表 | SQLite score_segments | 年度更新（用户上传） |
| 批次线 | SQLite province_cutoffs | 年度更新（用户上传） |
| 招生计划 | SQLite admission_plans | 年度更新（用户上传） |
| 就业数据 | SQLite 4张投研表 | 年度更新 |
| 城市数据 | Neo4j City节点 + SQLite city_data | 年度更新 |
| 院校数据 | Neo4j University节点 + SQLite universities | 年度更新 |
| 专业数据 | Neo4j Major节点 + 爬取数据 | 年度更新 |
| 薪资数据 | Neo4j SalaryData节点 | 季度更新 |
| 政策数据 | Neo4j Policy节点 | 实时更新 |

-------------------------

| 场景 | 缺失数据 | 引导话术 | 接受格式 |

| 查询录取线 | 无该校数据 | 请上传成绩单或招生简章 | 图片/PDF |

| 查询就业数据 | 无统计 | 请上传就业质量报告 | 图片/PDF |
| 查询院校详情 | 信息不全 | 请上传院校官网截图 | 图片 |
